Importar Productos desde Excel

Selecciona un archivo Excel con los productos a importar. El archivo debe contener las siguientes columnas:

  • sku - Código del producto (requerido)
  • descripcion - Descripción (requerido)
  • marca - Marca (opcional)
  • modelo - Modelo (opcional)
  • proveedor - Nombre del proveedor (opcional)
  • categoria - Categoría (opcional)
  • costo - Costo unitario (opcional)
  • precio - Precio de venta sin IVA (opcional)
  • iva - IVA porcentaje (opcional, default 21)
  • stock - Cantidad en stock (opcional)

Formatos soportados: Excel (.xlsx, .xls)
